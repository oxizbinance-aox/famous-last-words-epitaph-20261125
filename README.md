## The epitaph

> I told you the brakes were fine.

One concrete moment — the argument about the brakes right before the drive — with the twist landing in the last two words: they were fine, and that is exactly why he is dead.

## Run

```sh
node main.ts
```

`main.ts` writes the single line to `/output/entry.txt` (creating `/output` if needed), verifies the saved bytes match the line, and prints exactly the line to stdout.
